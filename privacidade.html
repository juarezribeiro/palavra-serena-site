Política de privacidade

Palavra Serena · atualizada em 14 de outubro de 2026

Este site

Este site apenas apresenta o canal e os links das redes sociais. Ele não usa cookies, não tem formulários e não coleta dados de quem o visita.

Aplicativo Palavra Serena Uploader

O Palavra Serena Uploader é uma ferramenta de uso interno. Ela é usada somente pelo administrador do canal para enviar e agendar os vídeos do próprio canal no YouTube, por meio dos Serviços de API do YouTube. O aplicativo não é oferecido ao público e não acessa contas de outras pessoas.

Com a autorização do administrador, o aplicativo acessa da conta do YouTube do canal apenas o necessário para essa tarefa:

  • informações básicas do canal (nome e identificador), para saber em qual canal publicar;
  • envio de vídeos, miniaturas e legendas, e definição da data de publicação;
  • lista dos vídeos do próprio canal, para conferir o que já foi enviado.

As credenciais de acesso ficam guardadas apenas no computador do administrador. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. O uso dessas informações segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Ao usar os Serviços de API do YouTube, aplicam-se também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Com isso, as credenciais guardadas deixam de funcionar.
